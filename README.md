# 事業候補マップ

事業の可能性を広げ、5つの軸で採点し、順位と配置で絞り込むためのマインドマップツール。
HTML 1ファイルだけで動きます。ビルド不要、サーバー不要。

## 使い方

`index.html` をブラウザで開くだけ。GitHub Pages に置けば、URLからいつでも開けます。

- **地図** … ノードをタップで選択、ドラッグで移動、ダブルタップで改名。右下の■で枠のサイズ変更
- **順位** … 5軸の重みを動かすと順位が並び替わる
- **配置** … 実現性 × 魅力度のマトリクス

形・色・書体・つなぎ線のデザインは「見た目」から変更できます。

## データの保存先

**ブラウザの localStorage** に保存されます。つまり:

- 編集は自動保存され、次に同じURLを開くと続きから使えます
- データはこの端末・このブラウザの中だけにあり、リポジトリには一切含まれません
- PCとスマホでは別のデータになります（同期しません）
- ブラウザのサイトデータを削除すると消えます

大事なマップは **「バックアップ(JSON)」** で書き出しておいてください。
別の端末やブラウザで開き直すときは、マップ名のバー → **「読み込む」** からそのJSONを取り込めます。

## GitHub Pages への公開

1. リポジトリに `index.html` を置く
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## 更新するとき

`index.html` を上書きコミットするだけ。URLが変わらないので、保存済みのデータはそのまま残ります。

## 印刷

マップ右上の ⎙ から、A4の縦・横を選んで1枚に収めて印刷できます（PDF保存も可）。
ダークモードで作業していても、印刷とPNG書き出しは白背景で出力されます。
